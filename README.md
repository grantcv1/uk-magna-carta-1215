# Magna Carta of 1215 in Akoma Ntoso

The Magna Carta of 1215 in Akoma Ntoso XML, with its Latin text, an English translation, and a CSS stylesheet that renders the document in a medieval manuscript manner in a web browser. It was generated by Claude for Grant Vergottini.

## Files

| File | Purpose |
| --- | --- |
| `magna-carta-1215.xml` | The Akoma Ntoso document |
| `magna-carta-1215.css` | The stylesheet, linked from the XML |
| `index.html` | Landing page for GitHub Pages |

To view the document locally, keep the XML and CSS files in the same folder and open the XML in a browser.

## About the markup

- **Standard:** Akoma Ntoso 2.0 (AKN 3.1). The namespace is `http://docs.oasis-open.org/legaldocml/ns/akn/3.0`, with `version="3.1"` on the root element.
- **Validation:** The XML validates against the Akoma Ntoso 2.0 cs01 schema.
- **Latin text:** The charter is an `<act name="charter">` in Latin, with its salutation and grant in the `<preamble>` and 63 `<clause>` elements in the `<body>`.
- **English translation:** The translation is a `<doc name="translation">` in an `<attachment>`, with its own metadata. `FRBRtranslation` links it to the Latin expression, and its clause eIds use the same numbers with an `att_english__` prefix.
- **Editorial additions:** The original runs continuously, with no title or clause numbers. The title in `<preface>` and the numbers in `<num>` are editorial, and the numbering follows the convention used by McKechnie.
- **Dates and places:** The date and place of grant are marked with `<date>` and `<location>` in clause 63. Named persons in the text are not marked up.
- **Jurisdiction:** The URIs use `gb-eng`, for England.

## Sources

Latin text and English translation: William Sharp McKechnie, *Magna Carta: A Commentary on the Great Charter of King John*, second edition (1914), as transcribed by [Project Gutenberg](https://www.gutenberg.org/ebooks/65363). Footnote markers and page numbers were removed, and spelling is unchanged.

The translation is McKechnie's, and it reflects his reading of the text. Modern translations may differ.

## Fonts

The stylesheet embeds Almendra, IM Fell English and UnifrakturCook, all licensed under the [SIL Open Font License](https://openfontlicense.org/). The rendering evokes a manuscript; it does not reproduce the handwriting or layout of any surviving copy.
